### L-M2. "emoji ... are still replaced" / "Each such character used to become `-`"

get the one-time move even though no letter is kept:
```
"/home/u/projects/🚀"    old= "projects----"    new= "projects---"    CHANGED
"/home/u/projects/🚀app" old= "projects----app" new= "projects---app" CHANGED
"/home/u/p/𠀀"          old= "p----"           new= "p--𠀀"           CHANGED
```
Corrected: add "A name with an emoji or another character outside the Basic Multilingual Plane
also changes id (it used to become two `-`, now one)."

### F1. hook-handoff.mjs:717 (comment added in 23a4f32)
