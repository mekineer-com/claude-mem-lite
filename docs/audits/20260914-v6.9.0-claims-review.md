## FALSE

### F1. The `session-start` delta is arithmetically impossible, and it is wrong in three copies

Written in **`54fce6f` (commit body)**, **`docs/measurement/rulers.md:62`** (tracked, shipped)
and **`.converge/LOG.md:259`**:

> `hook.mjs session-start            99.1   +81.2`

and in rulers.md verbatim:

> `session-start 99.1 (+81.2)`

The floor printed in the same table is **16.4**. `99.1 − 16.4 = 82.7`. **+81.2 cannot be
produced from those two numbers under any rounding.** Every other delta in the same table is
exact: `73.6−16.4=57.2` ✓, `83.6−16.4=67.2` ✓, `32.8−16.4=16.4` ✓, `46.5−16.4=30.1` ✓,
`83.6−73.6=10.0` ✓ — so this is one transcription slip, not a different run.

The ruler's own source docblock (`benchmark/hook-latency.mjs:38`) carries **`+82.8`**, which
*is* consistent. So the correct value exists in the tree and the wrong value is in the two
places a reader quotes from (rulers.md is the file CLAUDE.md tells you to read before quoting
a ruler).

Measured: the tool computes deltas itself and never gets them wrong —
```
cd scratchpad/rev-claims && MEM_NO_AUTO_ADOPT=1 node benchmark/hook-latency.mjs -n 15
  node -e '' (floor)             17.6
  hook.mjs session-start         99.2   +81.6      # 99.2 − 17.6 = 81.6, exact
```
Fix: `+82.8` in `rulers.md`, `LOG.md` and (if amended) the commit body.
